# HeliosEDU

Электронная образовательная среда в духе Moodle и «Прометея», но вокруг человека, который учится:
видно, что уже сделано и с чего продолжить. Учебный проект ПГГПУ, факультет информатики и экономики (ИНЭК), группа М1227.

**Фронтенд:** Next.js 16 · React 19 · TypeScript 6 · Tailwind CSS 4 · SWR · Zustand
**Бэкенд:** ASP.NET Core (.NET 10) · EF Core · PostgreSQL
**Инфраструктура:** Docker · GitHub Actions · ESLint + Prettier

Что сделано и что дальше — в [ROADMAP.md](ROADMAP.md).

## Быстрый старт

Нужен Node 24 LTS (`.nvmrc`).

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000 → «Вход» → выберите, кем войти (студент, преподаватель, организатор, администратор).
Пароль в демо-режиме не нужен.

Всё в Docker: `docker compose up --build`.

## Два режима данных

Переключатель «данные: Демо | Сервер» — в шапке кабинета и на странице входа.

| | Демо | Сервер |
| --- | --- | --- |
| Данные | моки в памяти Next.js (сбрасываются при перезапуске) | PostgreSQL через C# API |
| Вход | выбор роли, без пароля | почта и пароль, сессия в httpOnly-cookie |
| Права | те же правила, что на сервере | проверяет C# API и `src/proxy.ts` |
| Когда нужен | показ, разработка интерфейса | проверка настоящей связки с бэкендом |

Серверный режим включается переменной `BACKEND_API_URL` — запуск API, базы и демо-аккаунты описаны
в [backend/README.md](backend/README.md). Часть функций в C# ещё в работе: такие разделы в режиме «Сервер»
честно отвечают «ещё не подключено» (см. [ROADMAP.md](ROADMAP.md)).

## Устройство

```
src/app/          страницы и app/api — маршруты Next (моки и пересылка в C#)
src/features/     фичи: auth, dashboard, courses, course-builder, player, quiz, assignment,
                  gradebook, submissions, analytics, hub, programs, admin, notifications
src/shared/       ui-кит, права (permissions, management), layout, lib, types
src/mocks/        демо-данные и хранилища в памяти
src/proxy.ts      проверка сессии и прав для API в серверном режиме
backend/          C# API, миграции, тесты на настоящем PostgreSQL
docs/backend/     задания для бэкенда: контракты, права, тексты ошибок, тесты
```

- **API-first:** интерфейс получает данные только через `/api/*`; один контракт для моков и C#.
- **Права** — в одном месте: `shared/auth/permissions.ts` (`can`) и `shared/auth/management.ts`;
  на сервере их повторяет C# (`AccessRules`).
- **Бренд «Ясное небо»:** токены в `src/app/globals.css`, правила — `docs/design-audit/`.

## Как мы работаем

Вдвоём и с ИИ-агентами (Claude Code, Codex). Общие правила — в [AGENTS.md](AGENTS.md).

- В `main` только через PR: зелёный CI (типы, линтер, сборка, тесты C#, Docker) → ревью → squash merge.
- Перед PR: `npm run check` и `npm run build`.
- PR делаем от `main` по одному — цепочки PR при squash-слиянии приходится переносить вручную.
