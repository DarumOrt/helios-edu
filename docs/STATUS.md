## Сейчас — сверено 27.11.2026

- При выделении в просмотрщике PDF и офисных копий остаётся подсветка, а буквы берутся с canvas. Текстовый слой использует стандартный режим отрисовки браузера, чтобы метрики PDF.js не зависели от стиля сайта. На демо-PDF в Chrome при 390 px проверили выделение мышью и копирование.
- Этап 4 просмотра материалов в локальном `main`. Конспект принимает PDF, DOC, DOCX, ODT, RTF и TXT. Gotenberg готовит PDF-копию при загрузке, оригинал можно скачать. В Chrome проверили DOCX с кириллицей, формулой и таблицей, сохранение прогресса со второй страницы и TXT в отдельной вкладке при ширине 390 px. Через API подтвердили просмотр и совпадение скачанного оригинала для всех шести форматов, отказ постороннему студенту и ответ 422 на DOCX без заголовка ZIP. Миграций нет.
- Этап 5 в локальном `main`. Администратор создаёт межфакультетские разделы в «Управление курсами». Раздел появляется в каталоге с двумя действующими факультетами и хотя бы одним опубликованным курсом, видимым пользователю. Состав раздела управляется отдельно от записи на курс. Миграция `CatalogCollections` применена локально. В Chrome при 390 px проверили создание, правку и удаление раздела, карточку курса для студента без записи и отказ организатору в управлении. Прошли целевой тест каталога на PostgreSQL, сверка OpenAPI, `npm run check`, сборки Next и C#.
- Видео, PDF и презентации в новой вкладке открываются в просмотрщике без меню и с тем же прогрессом. PDF сохраняет высоту до отрисовки следующей страницы. Конспект загружается без поля ссылки, презентации принимают PPTX, PPT, ODP и PDF. В Chrome проверили высоту 331 px при перелистывании на ширине 390 px, продолжение PDF с третьей страницы в новой вкладке, загрузку PPTX из двух слайдов и скачивание оригинала. Прошли `npm run check`, сборки Next и C#, сверка контракта API. Рабочий сервер и полный прогон серверных тестов не проверяли.
- Исправлен первый просмотр загруженного видео и PDF. Если записи прогресса ещё нет, API возвращает JSON `null`. При сбое запроса прогресса материал открывается с сообщением. В Chrome воспроизвели загруженное видео из хранилища, при подставленном HTTP 503 проверили воспроизведение на 390 px и отрисовку PDF. Прошли `npm run check`, `npm run build` и сборка C#.
- Этапы 1–3 сведены в локальный `main`. Применены `CourseExclusions` и `MediaViewingRanges`, типы сверены с локальным API. Прошли `npm run check` (67 модульных тестов и 2 проверки инструментов) и `npm run build`, собран образ C#. Локальный сайт доступен на порту 3000. Выпуск на рабочем сайте не проверяли.
  В Chrome открыли «Участники» от преподавателя в режиме «Сервер», содержание курса, PDF в двух вкладках и плеер видео в демо. На ширине 390 px PDF открывается без горизонтальной прокрутки страницы.

## Ключевые решения (не пересматривать без обсуждения с владельцем проекта)

| Решение | Где подробнее |
| --- | --- |
| Приоритет новых возможностей — режим «Сервер» (C# + PostgreSQL); демо остаётся для быстрого просмотра интерфейса, недоступное в нём — понятная заглушка | AGENTS.md |
| Сайт для разработки — `npm run dev`; в Docker только сервер: `docker compose --profile backend up -d --build db storage api` (у `web` свой профиль) | AGENTS.md |
| Хранилище файлов — SeaweedFS через S3 (MinIO заархивирован) | [ADR 0001](adr/0001-object-storage.md) |
| Ученик курса — студент назначенной группы или индивидуально записанный студент (вручную или по кодовому слову), по правилу `AccessRules.CourseStudents` | [ADR 0003](adr/0003-course-enrollment.md) |
| Преподаватель создаёт свои курсы и управляет записью на них | [ADR 0003](adr/0003-course-enrollment.md) |
| Оценки принадлежат студенту: курс остаётся в «Моих оценках» после перевода и пока он в корзине; после окончательного удаления рейтинг без него | [P8](backend/p8-trash-accounts.md) |
| Корзины (материалы, курсы, файлы) — 7 дней; файлы сданных работ не удаляются | [P6](backend/p6-files.md), [P8](backend/p8-trash-accounts.md) |
| Удалённый пользователь с данными обезличивается («Удалённый пользователь»), без данных — удаляется | [P8](backend/p8-trash-accounts.md) |
| Журнал действий — только добавление, бессрочно, видит администратор; неудачные входы — с почтой, без пароля и IP | [P3–P4](backend/p3-p4-notes.md) |
| Лимит попыток теста задаёт преподаватель, по умолчанию без лимита; новая попытка — только кнопкой | [P5](backend/p5-adaptive.md) |
| E-mail одногруппников студентам не показываем; лидерборд — вся группа с именами | [P7](backend/p7-tracking.md) |
| Загрузка: видео mp4/webm до 1 ГБ, конспект и презентация до 50 МБ, обложка jpg/png/webp до 5 МБ, файл работы до 50 МБ | [P6](backend/p6-files.md) |

## Ловушки окружения

- .NET SDK локально нет: сборка — `npm run build:backend`, миграция —
  `node scripts/run-bash.mjs scripts/dotnet.sh migration <Имя>` (через Docker).
- На Windows обычный `bash` может вести в WSL. npm-команды используют обёртку `run-bash.mjs`,
  которая находит Git Bash рядом с установленным Git. Глобальный PATH не меняем.
- Тесты бэкенда — только `npm run test:backend` (свой стек heliostest, порядок CI, сбросы лимита входов);
  гонять по одному на машину, не параллельно с другой сборкой C#.
- `npm run build` в той же папке, где идёт `npm run dev`, роняет dev-сервер (общая `.next`).
- В Git Bash пути для `docker run` искажаются — скрипты ставят `MSYS_NO_PATHCONV=1`.
- `docker compose down -v` удаляет том `mail_keys`: пароль SMTP и письма в очереди перестают читаться
  (настроить SMTP заново). На сервере ключи копировать вместе с базой.
- После слияния PR с миграцией: сначала `git pull`, потом пересборка сервера.
- Если встроенный браузер не дорисовал потоковую страницу, проверить состояние страницы и логи;
  не считать HTTP 200 достаточной визуальной проверкой и не требовать старый инструмент `get_page_text`.
- `gh` в Git Bash не в PATH: `"/c/Program Files/GitHub CLI/gh.exe"`.
