## Ловушки окружения

- .NET SDK локально нет: сборка и миграции — `bash scripts/dotnet.sh build | migration <Имя>` (через Docker).
- Тесты бэкенда — только `npm run test:backend` (свой стек heliostest, порядок CI, сбросы лимита входов);
  гонять по одному на машину, не параллельно с другой сборкой C#.
- `npm run build` в той же папке, где идёт `npm run dev`, роняет dev-сервер (общая `.next`).
- В Git Bash пути для `docker run` искажаются — скрипты ставят `MSYS_NO_PATHCONV=1`.
- `docker compose down -v` удаляет том `mail_keys`: пароль SMTP и письма в очереди перестают читаться
  (настроить SMTP заново). На сервере ключи копировать вместе с базой.
- После слияния PR с миграцией: сначала `git pull`, потом пересборка сервера.
- Встроенный браузер в скрытой панели не дорисовывает потоковые страницы (висит «загрузка») —
  проверять через `get_page_text`/запросы или переход внутри приложения.
- `gh` в Git Bash не в PATH: `"/c/Program Files/GitHub CLI/gh.exe"`.
