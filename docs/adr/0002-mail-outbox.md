# 0002. Почтовая очередь в PostgreSQL и одноразовая активация

Статус: принято, 13 ноября 2026.

## Контекст

Нужны CSV-импорт, приглашения и массовые письма. HTTP-запрос не должен ждать всю рассылку;
перезапуск API не должен терять очередь. Проект уже использует PostgreSQL и фоновые сервисы .NET.

## Решение

- Сохраняем outbox (`MailCampaign`, `MailRecipient`) вместе с бизнес-изменением в одной транзакции.
  Worker использует advisory lock PostgreSQL, одинаковый для всех экземпляров. Отдельный брокер не нужен.
- SMTP — MailKit 5.0.0 с проверкой TLS-сертификата и явным STARTTLS/SSL-on-connect.
  Текстовый и HTML варианты — multipart/alternative; адресат видит только собственный адрес.
- Одинаковый UUID операции + fingerprint возвращает прежний результат. Уникальные индексы защищают гонки.
- Секрет SMTP и тела очереди защищаем ASP.NET Data Protection; ключи — отдельный постоянный volume.
  Приглашение содержит случайный токен, в таблице активаций — только хеш и срок.
- Изменения аккаунтов, назначений и публикации собираются из EF ChangeTracker до асинхронного сохранения.
  Сид отключает события явно; повтор без изменений не создаёт писем. Существующие назначения не мигрируем:
  таблица `CohortCourses` уже many-to-many и использовалась в правилах доступа.

## Последствия

- Скорость ограничена одним письмом в секунду на БД, временные отказы — до трёх попыток.
- SMTP не гарантирует exactly-once. Авария после принятия письма, но до фиксации результата, требует проверки
  администратором: автоматический повтор такой отправки запрещён. В истории это ошибка с неизвестным результатом.
- Ключи надо резервировать вместе с БД и разделять между экземплярами API.
- Новые аккаунты CSV не получают известный пароль до активации; существующий сценарий временного пароля
  ручного создания сохраняется. Изменение email/пароля или статуса отзывает старые ссылки.
- Один студент по прежнему состоит в одной учебной группе. Импорт переводит его в новую группу только
  при явном выборе администратора; множественность групп относится к курсу.
