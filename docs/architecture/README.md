# Архитектура и справочник API HeliosEDU

Руководство для разработчика по состоянию кода `main` на 29 октября 2026 года,
коммит `7aaf732e278fc2a3ca8cdf41030e5f9c41cd0e4f`.
Ссылки на исходники внутри документов закреплены на этом коммите.

- [Архитектура проекта](helios-architecture.html): 28 разделов, интерактивная схема сервисов,
  путь запросов в Демо и Сервере, сессии и права, EF Core, 29 таблиц, P5/BKT,
  SeaweedFS, работы и оценки, уведомления, трекинг, аудит и корзины.
- [Справочник API](helios-api-reference.html): все 86 HTTP-операций из сохранённого OpenAPI,
  права, параметры, примеры JSON и cURL, ошибки и просмотр 51 схемы DTO.

## Как открыть

GitHub отображает исходный код HTML. Скачайте оба файла в одну папку и откройте
`helios-architecture.html` или `helios-api-reference.html` браузером.
В локальном клоне достаточно открыть файл из этой папки. Сервер для чтения не требуется.

Оба документа содержат собственные стили, JavaScript и данные. Они работают офлайн;
сеть нужна только для переходов на GitHub. Между страницами есть взаимные ссылки.
Примеры cURL можно скопировать, но страницы сами не отправляют запросы в API.

В руководстве есть поиск (`Ctrl K`), переключение режима на схеме, просмотр таблиц и
симулятор BKT. Справочник фильтруется по тексту, модулю и HTTP-методу. Доступны
светлая/тёмная тема и печать в PDF.

## Как поддерживать актуальность

- Проверять маршруты и схемы по `docs/api/openapi.json` и зарегистрированным endpoints C#.
- Проверять таблицы, поля и ключи по `LearningDbContextModelSnapshot.cs`.
- Права, динамические JSON-запросы и бизнес-ошибки сверять с обработчиками,
  а путь через Next — с `src/shared/lib/backend.ts` и Route Handlers.
- Обновлять обе страницы вместе, включая номер среза и закреплённые ссылки на исходники.
- Проверять поиск, фильтры, копирование примеров, навигацию и JavaScript в браузере;
  затем выполнять `npm run check` и `npm run build`.

OpenAPI пока не описывает все динамические тела и ошибки; отдельные `.Produces` также
указывают 200 вместо фактического 201. Справочник дополняет схему по коду обработчиков
и явно отмечает эти ограничения.
