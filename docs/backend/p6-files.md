# P6. Файлы курсов в хранилище

Решение и выбор хранилища — [ADR 0001](../adr/0001-object-storage.md). Код — `backend/HeliosEdu.Api/Files/`,
тесты — `backend/tests/files.test.mjs`. Работает только в режиме «Сервер»; в демо кнопки загрузки неактивны.

## Как устроено

```
браузер ── POST /api/files ──────────► C#: права, формат, размер → запись Files (pending) + ссылка PUT
браузер ── PUT uploadUrl (файл) ─────► хранилище (SeaweedFS, S3), напрямую, с прогрессом
браузер ── POST /api/files/{id}/complete ► C#: файл на месте, размер совпал → ready
браузер ── GET /api/files/{id} ──────► C#: доступ → 302 на временную ссылку хранилища (Range работает)
```

Ссылки на загруженные файлы хранятся строкой `/api/files/{id}`: `Activity.Src` (видео, PDF, презентация),
`Course.Cover`, `Submission.FileId`. Старые адреса `/media/…` и внешние `https://…` продолжают работать.

## Виды файлов (`FileKinds` = `src/shared/lib/file-rules.ts`)

| `kind` | Форматы | Размер | Кто загружает |
| --- | --- | --- | --- |
| `video` | mp4, webm | до 1 ГБ | тот, кто правит курс |
| `document` | pdf | до 50 МБ | тот, кто правит курс |
| `cover` | jpg, jpeg, png, webp | до 5 МБ | тот, кто правит курс |
| `submission` | pdf, doc, docx, odt, pptx, xlsx, txt, zip, png, jpg, jpeg | до 50 МБ | студент курса |

Тип файла (`contentType`) назначает сервер по расширению; браузер отправляет PUT именно с ним.

## Эндпоинты

Изменяющие запросы — с `X-Helios-Client: web`. Ошибки — `{ error, fields? }`. Хранилище не подключено — `503`.

| Метод и путь | Тело | Ответ |
| --- | --- | --- |
| `POST /api/files` | `{ kind, courseId, fileName, size }` | `201 UploadTicket { id, uploadUrl, contentType, expiresAt }` (ссылка — 1 час). `400 fields.kind = "Неизвестный вид файла"`, `fields.fileName = "Этот формат не подходит. Можно: …"`, `fields.size = "Файл пустой"` / `"Файл больше 1 ГБ"`; курс не виден — `404`; нет прав — `403` |
| `POST /api/files/{id}/complete` | — | `200 StoredFileInfo { id, kind, courseId, fileName, contentType, size, url }`. Не загружен — `409 "Файл не загружен — попробуйте ещё раз"`; размер не совпал — файл удаляется, `400 fields.size`; чужая запись — `404` |
| `GET /api/files/{id}` | — | `302` на временную ссылку (1 час). Нет доступа или файл не готов — `404` |
| `POST /api/files/cleanup` | — | только администратор: `200 CleanupResult { abandoned, trashed, restored, deleted, orphans }` |
| `PUT /api/courses/{id}/cover` | `{ coverColor?, cover? }` | `200 CourseSummary`; `cover` — `/api/files/{id}` вида `cover` этого курса или `null`. `400 fields.coverColor = "Неизвестный цвет обложки"`, `fields.cover = "Картинка не найдена — загрузите её ещё раз"` |

Материал (`POST/PATCH …/activities`) с `src = /api/files/{id}` принимается, только если файл этого курса и
подходящего вида (видео — `video`, PDF и презентация — `document`): иначе `400 fields.src = "Файл не найден —
загрузите его ещё раз"`. Сдача работы принимает `fileId` своего файла вида `submission`: иначе `400 fields.fileId`.

**Кто читает:** обложку — все вошедшие (она в каталоге); файлы курса — те, кому виден курс;
файл работы — автор и проверяющие курса (администратор, преподаватель своего курса).

## Корзина и очистка (`FileJanitor`, по образцу Moodle)

Раз в `Storage:CleanupMinutes` (60):

| Что | Когда | Что делаем |
| --- | --- | --- |
| загрузка брошена (`pending`) | старше суток | удаляем объект и запись |
| файл не нужен (заменили видео или обложку, удалили материал, пересдали работу до проверки) | сутки без ссылок | в корзину (`trash`), из корзины не открывается |
| на файл снова сослались | — | из корзины обратно в `ready` |
| файл в корзине | 7 дней | удаляем объект и запись |
| объект в хранилище без записи | старше суток | удаляем |

Сданная работа всегда ссылается на свой файл — файлы работ не удаляются вместе с материалом.
Видимая «Корзина курса» с восстановлением материалов — следующий шаг.

## Настройки (`compose.yaml`, `.env.example`)

`Storage__ServiceUrl` (адрес для C#), `Storage__PublicUrl` (адрес для браузера — на него выписываются ссылки),
`Storage__AccessKey`, `Storage__SecretKey`, `Storage__Bucket`, `Storage__AllowedOrigins` (CORS),
`Storage__CleanupMinutes`. Хранилище создаётся само при старте C#.
