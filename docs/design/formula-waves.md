# Волны из формул

Фон из демо-ролика HeliosEDU используется на входе, регистрации и в приветствии кабинета.
Тема сайта выбирает вариант «небо» или «ночь». Приветствие по-прежнему зависит от времени суток.

## Палитра «Ясное небо»

Фирменный синий `#1D66CC` (`--primary` в светлой теме) обозначает действия. Солнечный `#FFC53D` (`--sun`)
остаётся акцентом для достижений. Для текста на светлых волнах используется глубокий синий из текущей
палитры интерфейса (`--waves-ink`), а на тёмных — светлый. Шрифты интерфейса — Golos Text и JetBrains Mono.

| Токен | Небо | Ночь |
| --- | --- | --- |
| `--waves-from` | `#CDE2F7`, верх градиента | `#070C18`, общий базовый цвет |
| `--waves-to` | `#F3F7FC`, низ градиента | `#070C18`, общий базовый цвет |
| `--waves-depth` | `−18 −10 −2` по RGB, гребни чуть темнее | `+11 +24 +56` по RGB, гребни до `#122450` |
| `--waves-line` | `+8 +6 +3` по RGB, мягкие светлые линии | `+10 +20 +40` по RGB, около 45% от яркости линий в ролике по каждому каналу |

Токены заданы в `src/app/globals.css`. В пустых состояниях тот же мотив передают лёгкие CSS-кольца
с основным цветом темы и прозрачностью 93%. Формы и таблицы используют обычные поверхности сайта.

## Как получаются линии

`FormulaWaves` складывает три синусоиды и радиальную волну с весом 0,7. Получается условная высота `w`
для каждой точки. Изолинии проходят там, где дробная часть `1.7 × w` близка к `0.5`:

```text
k = (w + 3.7) / 7.4
dist = abs(frac(1.7 × w) − 0.5)
width = max(0.055, изменение 1.7 × w по соседним пикселям)
line = max(0, 1 − dist / width) × (0.055 / width)
цвет = lerp(верх, низ, y / (высота − 1)) + глубина × k + подсветка × line
```

Коэффициент 1,7 задаёт частоту линий, а 0,055 — их толщину. Одна единица поля занимает около
220 CSS-пикселей. Холст примерно втрое меньше блока, максимум 640 пикселей по стороне.
Для сглаживания тонких линий компонент оценивает изменение высоты по горизонтали и вертикали.
Если линия уже шага сетки, её цвет распределяется по соседним пикселям.
Фаза начинается с `t = 7.3` и растёт на 0,25 за секунду. `requestAnimationFrame` синхронизирует
отрисовку с браузером. Синусы и косинусы считаются по строкам и столбцам, радиальная часть
кешируется при изменении размеров. Анимация приостанавливается вне экрана и в скрытой вкладке.
При включённом уменьшении движения фон статичный и перерисовывается при смене темы или размера.
