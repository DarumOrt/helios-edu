# Модуль «deploy» — выкладка на сервер и установка у организаций

Устав и отчёт модуля (≤40 строк). Общие файлы (см. AGENTS.md → «Модули») меняет основная сессия.
Инструкция для владельца и для организации — [docs/deploy.md](../deploy.md).

## Зона
- `compose.prod.yaml`, `Caddyfile`, `.env.prod.example`, `scripts/server/` (compose, deploy, backup, restore),
  `.github/workflows/deploy.yml`, `docs/deploy.md`; в C# — `Auth/FirstAdmin.cs`, `Auth/ClientAddress.cs`

## Решено с владельцем проекта (14.11)
- Timeweb: обычный облачный сервер (Ubuntu 24.04, Москва, 2 ядра / 4 ГБ / от 50 ГБ), без «Баз данных» и App Platform:
  проект должен переноситься на сервер организации (нужны только Linux, Docker, домен, почта).
- Один домен `heliosedu.ru`: сайт — `heliosedu.ru`, файлы — `files.heliosedu.ru`. Перед сайтом — Caddy (HTTPS сам).
- Образы собирает GitHub Actions (GHCR), сервер их только скачивает. На сервере руками ничего не правим.
- Выкладка — кнопкой «Run workflow» с номером версии (не на каждое слияние); перед ней — копия базы.
- База на сервере чистая, без демо-данных ПГГПУ; тестовые аккаунты — через импорт CSV.

## Готово (этап 0, 14.11) — проверено пробным запуском в локальном Docker
- Первый администратор: `Admin__Email` + `Admin__Password`, пока в базе нет администратора; пароль временный.
- Лимит входов по адресу пользователя: Caddy пишет `X-Real-IP` (присланный снаружи затирает) → Next
  (`TRUSTED_PROXY=on`) → C# `X-Helios-Client-Ip` (`Auth__TrustClientAddressHeader=true`). IPv6 — по сети /64.
  Локально и в тестах выключено: поведение прежнее.
- Тесты бэкенда с этими правками — 150/150, описание API не изменилось.
- `compose.prod.yaml`: наружу только Caddy; защищённые cookie, `DEMO_MODE=off`, без демо-данных, пароли из `.env`.
- Файлы: загрузка и чтение через `files.…` по временным ссылкам работают; наружу только `GET/HEAD/PUT/OPTIONS`
  в `/helios-media/*`. Работы студентов открываются в браузере (`inline`) с типом из списка разрешённых
  (HTML и SVG в списке нет) и `nosniff`.
- Копии: `backup.sh` (база, ключи почты, файлы), `restore.sh`; выкладка и откат: `deploy.sh` + `deploy.yml`.

## Не проверено
- `deploy.yml` целиком (нужны сервер и секреты), настоящий HTTPS-сертификат, вариант «за Nginx организации».

## Для переноса в организацию осталось
- `TenantId = "pspu"` зашит в коде (одна организация на установку — работает, но название внутреннее)
- Название организации, факультеты, группы — проверить, что задаются в интерфейсе, а не в коде
- Лицензия репозитория (решение команды); оператор персональных данных — организация

## Ловушки
- Cloudflare Tunnel из России не работает (режут соединения); для показа с домашнего ПК — российский туннель
- Откат версии не откатывает базу: после отката через миграцию — восстановить копию, снятую перед выкладкой
- `.version` хранит и адрес образов (`HELIOS_IMAGES`): копии и перезапуски без него взяли бы образы не оттуда
- Полная копия на минуты останавливает хранилище файлов — только ночью; `--no-files` — без остановки
