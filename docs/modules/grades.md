# Модуль «grades» — задания, сданные работы, журнал оценок, уведомления

Устав и отчёт модуля (≤40 строк). Сессия модуля читает этот файл вместо истории; в конце задачи обновляет
«Готово», «Ловушки», «Что осталось». Общие файлы (см. AGENTS.md → «Модули») — не трогать, а описать правку здесь
в «Для основной сессии».

## Зона
- C#: `backend/HeliosEdu.Api/Grades/`, `Notifications/`
- Next: `src/features/assignment/`, `submissions/`, `gradebook/`, `notifications/`, `src/app/(app)/gradebook|submissions/`,
  `src/app/api/assignment|submissions|gradebook|notifications/`, моки submissions/gradebook/announcements
- Тесты: `backend/tests/grades.test.mjs`, `notifications.test.mjs`

## Контракт
- Ответы — `Grades/GradesModels.cs`, `Notifications/*`; журнал = оценка преподавателя, иначе лучшая попытка P5

## Проверки модуля
`bash scripts/dotnet.sh build` · тесты бэкенда (grades/notifications) — только через `npm run test:backend` у основной сессии

## Готово
- Сдача с файлом, статус своей работы, повторная сдача с подтверждением, проверка и «Оценка выставлена»
- Журнал преподавателя, «Мои оценки» (курс остаётся после перевода и в корзине), «Скоро дедлайн»
- Объявления в колокольчике только студентам курса; преподаватель удаляет свои, управление — любые доступные
- Меню уведомлений: курсы, типы, непрочитанные, поиск и «Прочитать показанные»; [контракт](../backend/course-enrollment.md)
