# Как работаем сессиями Claude Code

Облегчённая версия метода «основная сессия + тематические». Полная схема (2–3 параллельные сессии волнами)
у нас не окупается: почти каждая задача сквозная — C#, миграция, контракт `domain.ts`/`api.gen.ts`, `proxy.ts`,
журнал действий, CI — а сервер на машине один (база, порт 8080, лимит входов, сборка C# в общую папку).
Поэтому главная экономия — **память в файлах и короткие сессии**, параллельность — только как исключение.

## Где память

| Файл | Что | Кто обновляет |
| --- | --- | --- |
| `docs/STATUS.md` | состояние `main`, ключевые решения, вехи, что дальше, что не проверено, ловушки окружения | основная сессия, в конце задачи |
| `docs/modules/<модуль>.md` | зона модуля, контракт, проверки, готово, ловушки, что осталось (≤40 строк) | сессия, работавшая в модуле |
| `docs/backend/p*.md`, `docs/adr/` | подробные контракты C# и решения по архитектуре | вместе с изменением |
| `ROADMAP.md` | план продукта | основная сессия |
| память Claude (auto-memory) | только предпочтения владельца и внешние ссылки | — |

Новая сессия читает `STATUS.md` и файл своего модуля, а не всю историю прошлых сессий.

## Роли

- **Владелец проекта** ставит цели, принимает решения, смотрит результат глазами, вливает PR.
- **Основная сессия** — одна на задачу: обсуждает, правит общие файлы, ведёт ветку → коммиты → PR,
  гоняет полный набор проверок, обновляет `STATUS.md`. Когда тема закончена — новая сессия или `/clear`.
- **Субагенты** (без правок кода): исследование «где это используется», ревью перед PR (безопасность, схема базы),
  функциональное тестирование ролей. Читают в своём окне и возвращают выжимку — основная сессия не засоряется.
- **Дополнительная сессия, которая пишет код** — только для двух по-настоящему независимых задач (см. ниже).

## Цикл задачи

1. Владелец формулирует, что нужно. Основная сессия читает `STATUS.md`, нужные `docs/modules/*.md`,
   при необходимости обсуждает решения и записывает их в `STATUS.md`.
2. Ветка от свежего `main` (`claude/<тема>`), по коммиту на задачу.
3. Проверки по ходу — точечные: `npm run typecheck`, `npm test -- <фильтр>`, `bash scripts/dotnet.sh build`.
4. Перед PR: `npm run check`, `npm run build`, при изменении C# — `npm run test:backend`; ревью субагентом, если менялись права или схема.
5. PR (ревью C# — второй разработчик), обновлённые `STATUS.md` и файлы модулей — в том же PR.
6. Владельцу — короткий итог: что поменялось, как проверено, что не проверено глазами, что сделать после слияния.

## Когда можно параллельно

Только если две задачи **не трогают общих файлов** (список — AGENTS.md → «Модули») и C# меняет не больше одной.
Пример: встроенный просмотр PDF (только Next, модуль learning) и лимит входа по адресу (только `Auth/`).

- Каждая дополнительная сессия — в своей рабочей копии (git worktree; `.worktreeinclude` копирует `.env.local`).
- Сессия получает бриф (шаблон ниже), не делает git, зависимости, миграции, dev-сервер и тесты бэкенда.
- Основная сессия сводит: забирает изменения, правит общие файлы, гоняет полный набор проверок, один PR.
- Не получилось гладко — возвращаемся к одной сессии; сведение важнее скорости.

## Шаблон брифа

```
Ты — сессия «<модуль>» проекта HeliosEDU. Прочитай CLAUDE.md, docs/STATUS.md, docs/modules/<модуль>.md.
Задача (владелец): <одной-двумя фразами>.
Сделать (только зона модуля): 1) … 2) …
Общие файлы не трогай — опиши нужную правку в «Для основной сессии» своего файла модуля.
Готово, когда: npm run typecheck и npm test -- <фильтр> зелёные, <ключевое> покрыто тестом,
docs/modules/<модуль>.md обновлён. Ответь 1–3 строками.
```

## Экономия токенов — коротко

- Короткие сессии и `/clear` между темами; `/compact` — когда всё важное уже в файлах.
- Читать точечно: grep и нужные строки, а не файлы целиком; не исследовать чужие модули.
- Повторяющееся — скриптами: `npm run test:backend`, `bash scripts/dotnet.sh`, `npm run api:types`.
- Проверки в браузере — текстом (`get_page_text`, запросы); скриншоты — когда без них никак.
- Модель по задаче: Sonnet — интерфейс и маршруты, Opus — схема, права, безопасность, Haiku — механика.
- CLAUDE.md держать коротким: он загружается в каждый запрос.
